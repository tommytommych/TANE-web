# TANE:i ご意見・ご質問フォーム構成案

TANE:iのユーザーからご意見・ご質問・不具合報告を効率よく収集するためのGoogleフォーム構成案。
LINE版・WEB版の両方から案内する想定。

**公開URL**: https://docs.google.com/forms/d/e/1FAIpQLSe_AS7xrjQuaa90Ao_E9bwbMwJFvqrNbM2UtKzQvq9sCNg14w/viewform

## 1. フォームのタイトル・説明文

**タイトル**

```
TANE:iへの声を聞かせてください🌱
```

**説明文**

```
いつもTANE:iをご利用いただき、ありがとうございます😊

「こんな機能があったら嬉しい」「ここが使いにくい」「こんな作品を作りたいけど相談したい」など、
どんな些細なことでも構いません。皆さんの声が、TANE:iを育てる一番の力になります🌱

回答は1〜2分ほどで完了します。いただいたご意見は今後のアップデートの参考にさせていただきます。
（LINE名やメールアドレスなどの連絡先は任意です。返信をご希望の場合のみご記入ください）
```

## 2. 質問項目リスト

| # | 項目名 | 回答形式 | 必須 | 選択肢・備考 |
|---|--------|----------|------|--------------|
| 1 | ご意見・ご質問の内容 | 記述式（段落） | 必須 | プレースホルダー例：「こんな機能が欲しい」「〇〇のやり方がわからない」など自由にご記入ください |
| 2 | カテゴリ | ラジオボタン | 必須 | ・機能へのご要望<br>・DIYの設計に関するご質問<br>・不具合報告<br>・その他 |
| 3 | 返信をご希望ですか？ | ラジオボタン | 必須 | ・返信を希望する<br>・返信は不要です |
| 4 | ご連絡先（メールアドレスまたはLINE名） | 記述式（短文） | 任意 | 「返信を希望する」を選んだ方はご記入ください（未記入の場合、返信できないことがあります） |

### 実装メモ（Google Forms設定時のヒント）

- 項目3「返信をご希望ですか？」は**セクション分岐**を使い、「返信を希望する」を選んだ場合のみ項目4（連絡先）のセクションに進む設定にすると、回答の手間を減らせる。
- 項目1は「回答の検証」で最小文字数を設けず、短い一言でも送信できるようにする（心理的ハードルを下げる）。
- 項目2はプルダウンではなくラジオボタン（選択肢を一目で見せる）を推奨。
